# Demo Script — 5 个核心场景

> 录屏 / 现场演示参考脚本。每个场景含：环境准备 · 用户台词 · AI 预期回答 · 失败兜底。
>
> 详细演讲稿在 `demo-script` todo 完成后落地。

## 1. 识物（厨房 / 书桌）
- 环境：摄像头对桌面 3-5 件常见物品
- 用户："前面是什么？"
- AI（预期）："桌上有一杯水，正前方；右侧放着一本书；左侧是你的眼镜。"
- 兜底（画面模糊）：AI 调用 `frame_quality_check`，引导调整距离

## 2. 读文字（药盒 / 名片）
- 用户："帮我读一下这个药盒"
- AI：调用 `set_mode(read_text)` → 朗读药品名 / 用法 / 剂量
- 兜底：文字太小 → 调用 `request_high_res_frame`

## 3. 找东西（钥匙 / 遥控器）
- 用户："我的钥匙在哪？"
- AI："请慢慢举起手机环顾房间。" → 看到时："找到了，在你右前方桌面靠近笔记本电脑的位置。"

## 4. 主动导航提醒
- 场景：用户行走，摄像头朝前
- AI（主动）："前方一米有台阶，向下三级，请扶好扶手。"

## 5. 多轮追问与打断
- 用户："前面是什么？"
- AI 开始播报…
- 用户中途："那个红色的呢？" → 前端检测语音，发送 `response.cancel`
- AI：立即停止当前回答，转接续上下文回答红色物品

## 演示 Checklist

- [ ] 手机充电、亮度调到可见即可
- [ ] 麦克风 / 摄像头权限已授权
- [ ] 网络在 4G 以上
- [ ] 备用本地后端窗口（演示掉线时切到 localhost）
- [ ] 提前录制视频兜底
