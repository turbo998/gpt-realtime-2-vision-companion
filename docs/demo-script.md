# Demo Script — 10 个可演示场景

> 现场/录屏演示参考脚本。每个场景包含：环境道具 · 用户台词 · AI 预期回答 · function call · 失败兜底。
>
> 演示总时长建议 8–12 分钟。前 30 秒打开界面 → 点开始 → 等"已连接 · gpt-realtime-2" toast。

## 通用准备

- 手机/平板横屏 or 笔记本外接摄像头
- 浏览器 Chromium 124+ / Safari 17+
- 提前授权麦克风 + 摄像头
- 屏幕右上观察"首句 / 总"延迟徽章应在绿色（<800ms）
- 桌面准备 10 件常见道具，按场景顺序拿出

---

## 1. 识物（书桌） 🪟
- **道具**：水杯、笔记本、眼镜、手机 4 件物品
- **用户**："前面是什么？"
- **预期 AI**："桌上有 4 样东西：正前方一杯水，右侧一台笔记本电脑，左前方一副眼镜，右下方一部手机。"
- **function call**：无（默认场景）
- **兜底**：画面模糊 → `frame_quality_check` → AI："画面有点模糊，能往后退一点吗？"

## 2. 读文字（药盒） 📖
- **道具**：常见药盒（如布洛芬）
- **用户**："帮我读一下这个药盒的用法用量。"
- **预期 AI**：调用 `set_mode(read_text)` → `request_high_res_frame(purpose="medicine_label")` → 朗读药品名/规格/适用症/用法用量
- **兜底**：字太小 → "把药盒再靠近 10 公分。"

## 3. 找东西（钥匙） 🔍
- **道具**：钥匙放在桌面某处或抽屉里
- **用户**："我的钥匙在哪？"
- **预期 AI**：`set_mode(find_object, target="钥匙")` → 引导环顾 → 找到："找到了，在你右手前方，红色书本旁边。"
- **兜底**：找不到 → "请慢慢转一圈摄像头，我帮你找。"

## 4. 纸币识别 💴
- **道具**：100 元 / 50 元 / 20 元各一张
- **用户**："这张是多少钱？"
- **预期 AI**：`request_high_res_frame(purpose="currency")` → "这是一张 100 元人民币。"
- **兜底**：背面 → "我看到的是背面，能翻一下吗？"

## 5. 菜单推荐 🍜
- **道具**：餐厅菜单（手机相册图也可）
- **用户**："帮我读一下这份菜单，有什么推荐？"
- **预期 AI**：`set_mode(read_text)` → 朗读 3-5 道菜 → "如果你口味清淡，可以试试那道番茄牛肉面。"
- **兜底**：图片倾斜 → "菜单有点斜，能放平一点吗？"

## 6. 红绿灯（安全场景） 🚦
- **道具**：路口照片 or 视频
- **用户**："现在能过马路吗？"
- **预期 AI**：`set_mode(navigation)` → "现在是红灯，请等一下。" → 切绿灯主动："变绿了，请直行通过。"
- **特殊**：若检测到来车 → `safety_alert(category="vehicle")` → 前端橙色横幅 + 振动

## 7. 公交/地铁 🚌
- **道具**：公交车正面照片（带线路号）
- **用户**："这是几路车？"
- **预期 AI**："这是 12 路，开往人民广场方向。"
- **兜底**：模糊 → `request_high_res_frame(purpose="bus_number")`

## 8. 路牌/门牌 🪧
- **道具**：门牌号 or 商店招牌
- **用户**："这个门牌写的什么？"
- **预期 AI**：`set_mode(read_text)` → "门牌号是 1503 号。"

## 9. 快递面单 📦
- **道具**：快递包裹面单
- **用户**："帮我看一下这个快递的信息。"
- **预期 AI**：`request_high_res_frame(purpose="shipping_label")` → 朗读寄件方/收件方/单号
- **隐私提醒**："为隐私保护，我可以只读单号最后 4 位，需要全念吗？"

## 10. 主动打断 + 多轮 🔁
- **用户**："前面是什么？"
- **AI** 开始播报…
- **用户中途插嘴**："那个红色的是什么？"
- **前端**：检测到 VU > 0.04 → `flushPlayback()` + `{type:"interrupt"}` → 服务端 `response.cancel`
- **AI**：立即停止当前回答，接续回答红色物品："红色那个是一本书，书名是《非暴力沟通》。"
- **验收**：右上"首句"徽章 < 800ms；扬声器停止 < 200ms
